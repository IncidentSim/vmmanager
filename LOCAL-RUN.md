# vmmanager: локальный запуск с настоящим Firecracker

← [Назад к README](README.md)

Готовый пример — архив `vmmanager-example.tar.gz`: все исполняемые файлы, Firecracker, ядро гостя, чистый
образ Ubuntu и готовые конфиги уже внутри, ничего скачивать и собирать на вашей машине не нужно.
В архиве есть короткий `README.txt` с командами; это руководство — обзор.

## Что нужно

Чистая Ubuntu 24.04 x86_64 с systemd и `/dev/kvm` (вложенная виртуализация подходит), оболочка root
(`sudo -i`), около 12 ГБ свободного места, доступ в интернет только для `apt`.

## Как запустить

Скачайте [vmmanager-example.tar.gz из v0.2.0](https://github.com/IncidentSim/vmmanager/releases/download/v0.2.0/vmmanager-example.tar.gz).
Распакуйте в `/opt`, чтобы файлы были доступны пользователю API:

```sh
sudo tar -xzf vmmanager-example.tar.gz -C /opt
sudo -i
cd /opt/vmmanager-example
```

Дальше выполните по порядку шаги 1–5 из `README.txt`: пакеты и пользователь, хранилище (файл на 10 ГБ с монтированием),
`vmhost install/setup`, запуск сокета helper, образ и конфиг, запуск API. Это **не «одна кнопка»**: бэкенду нужны отдельный
пользователь, смонтированное хранилище и systemd-юниты от root (изолированный VMM, квитанции о завершении),
поэтому хост готовится явно. API работает в обычном процессе на переднем плане (Ctrl-C — остановка), не службой.
Процессы VM, сеть и сокет хелпера — юниты systemd, остановка API их не трогает.

Откройте <http://127.0.0.1:8090/docs>, нажмите **Authorize** и вставьте токен из файла
`/var/lib/vmmanager/api/api-token` (создаётся на шаге 4 для каждой установки отдельно).

## Если что-то не работает

* Нет `/dev/kvm` — включите вложенную виртуализацию у гипервизора.
* `preflight` сообщает о пересечении подсети — выберите другой префикс вместо `10.222` (см. раздел Troubleshooting в `README.txt`).
* API сразу завершается — проверьте, что хранилище смонтировано: `findmnt /var/lib/firecracker-builder/storage`.
* Мало места — файл хранилища может вырасти до 10 ГБ.

## Сборка архива из исходников (для разработчиков)

Нужны Go, `fakeroot`, `squashfs-tools`, `e2fsprogs`; скачиваются закреплённые по хэшу артефакты:

```sh
make bundle BUNDLE_OUT=<каталог для архива>
```

Образ готовится при сборке (`internal/fixture`), в архив не попадают ключи или состояние какой-либо установки.

Происхождение: базовая версия исходников — коммит `92797338416f5bd84341d8d08e2724cb76b1ae47`.
